# ROS Playground

Here, we try to play with ROS with Pixi/Robostack for reproducibility.

## Details

We work on Lyrical as both Robostack and Open Robotics are working the most on
this distribution.

## Install

You need Pixi `>= 0.81`.

```sh
pixi install
```

## Develop in your venv

```sh
pixi shell
```
