# Simulation and AI for STK

Code to simulate the robot in its planning and pathfinding tasks, from the
onshape export to the visualization in the simulator.

> To clone the repository. You'll need `git-lfs` extension to be installed.
> This is to store and version the onshape-exported descriptions.

## 1. Description from OnShape

To export the robot description from OnShape, see the `onshape/` directory.
A version of the description is already tracked in the ROS Workspace. 

Tech stack in the sub-project: `uv`

## 2. ROS Workspace

See the `stk_robot_ws/` directory. It contains all the interesting stuff.

Tech stack in the sub-project: `pixi`
